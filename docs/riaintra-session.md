# RIAINTRA inactivity session

Staff authenticate with their SK-ID and password through the existing Wix member and staff authorization chain. The signed-in state is retained across reloads, navigation and browser restarts while the inactivity marker is valid. An authorized session lasts 30 minutes from the last observed interaction in an internal application. Normal pointer, keyboard, touch and scroll activity renews the shared marker, including across tabs. Expired or unavailable markers require sign-in again; explicit logout clears the marker. An old session from before this change requires a fresh sign-in.

The marker contains a timestamp, not credentials, and never grants staff access on its own. Staff authorization remains verified by the existing server-side services. The inactivity deadline is enforced by the Wix page controller and should not be represented as a server-enforced token expiration: directly calling an authorized backend method outside the UI is still subject to the Wix session lifetime and existing authorization. Interaction inside the Website Studio preview is forwarded through its verified preview channel. Other independently nested iframes may not reach the parent activity observer. Live Wix verification must cover reload, active use, idle expiration, multiple tabs and logout.
