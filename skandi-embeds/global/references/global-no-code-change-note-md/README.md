# Delivery scope

No source/runtime file has been modified in this package.

This package answers the requested Wix Studio configuration question and records the exact target settings per route.

A complete implementation of the target would require a separate approved code repair because:
1. CONTENT_AUTO pages need a common measured-height message contract if they do not already have one.
2. Current `masterPage.js` shows public/internal footers broadly; APP_VIEWPORT routes need route-aware footer suppression to prevent a second Wix-page scroll surface.
3. Each affected HTML_REF would need its INFO / LOG updated when that runtime behavior is implemented.

Those changes are deliberately not manufactured here because the request was for the exact settings/architecture, not for replacing every page implementation.
