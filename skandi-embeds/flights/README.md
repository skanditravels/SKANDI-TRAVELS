# INFO / LOG — Flights

- **Route:** `/flights` (existing `SITE_MAP.flights`).
- **Source:** `skandi-embeds/flights/skandi-flights.{html,css,js}`; the website builder generates `dist/flights/index.html` and `skandi-flights.receiver.html`.
- **Wix integration:** new page and HTML component `#flightsEmbed`; `src/pages/masterPage.js` authorizes that exact route/component and delegates `SKANDI_FLIGHTS_PAGE` messages to `src/public/flightsPageHost.js`. Wix Studio did not contain a Flights page when inspected on 2026-11-05; create it before installation.
- **Flight search:** Home-style airport, date, traveler and cabin controls; one-way or round trip. The host forces `tripType=flightOnly` and uses existing `public/bookingSearch.startBookingSearch`, which stores the search in the Wix session and navigates to `/booking?step=offer&searchId=...`. Booking's existing host and `customerBooking.web` search the canonical Duffel Air path. The page never calls Duffel or handles credentials directly.
- **Content:** `homeContent.web.getHomeContent` supplies public airports, featured destination cards and published Home card pricing. Flight offer cards require `homePriceProductType=flight_only`, a valid unexpired cached price, valid route/date/guest information and a currency matching the selected currency. Card totals describe their passengers and travel dates; choosing one reruns the underlying search in Booking. Last-minute cards are eligible flights departing within 30 days. No flight/hotel package card is presented as a flight. Offers remain empty until suitable existing Home Cards & Pricing records and cached prices exist. No inventory, schema or data changes are made by this page.
- **Editorial:** `src/public/siteMap.js` registers Flights presentation fields and image slots. Published presentation data and the existing website-design runtime provide editable presentation; featured destination images and flight prices retain their existing inventory/Media Control owners. The fallback hero image is the same image referenced in Home. Search label translations are a snapshot of the corresponding Home translations; the rest of the default page copy is English and can be edited through the presentation system.
- **Messages:** child `FLIGHTS_READY` / `FLIGHTS_REFRESH` → parent `FLIGHTS_CONTENT` or `FLIGHTS_ERROR`; child `FLIGHTS_SEARCH` → `FLIGHTS_OPENING` or `FLIGHTS_ERROR`. Requests carry `requestId`; read-only startup retries are bounded and search does not retry automatically. Navigation and presentation use the master controller's existing `MASTER_NAVIGATE`, `SKANDI_MASTER_CONFIG_REQUEST`, and `SKANDI_PRESENTATION_READY` contracts.
- **Verification:** local compiler, automated source/bridge tests and a desktop compiled-page preview. No Wix page, receiver, Duffel provider request, real pricing data, responsive Wix layout or Booking handoff has been tested live. A compiled build is not evidence of a Wix publication.
